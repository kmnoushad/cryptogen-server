# NEXIO v6.4 changes

## Why Futures produced zero candidates

The live diagnostic sample showed 283 scans, 0 armed candidates and 0 FIRE alerts. During bullish-enabled evaluations, the first gate simultaneously required a 0.60% three-minute move, a new 21-minute breakout, 1.50x volume and 56% taker buying. That identified only abrupt micro-pumps; it excluded steady advances spread over 15–30 minutes. The five setups that did pass were rejected by live liquidity/manipulation checks, which was correct for the thin books shown in the Supabase sample.

v6.4 keeps the original fast path and adds a separate steady-momentum path. The steady path requires sustained returns, positive EMA slope, net taker buying, price near the 21-minute high, acceptable wick/RSI/ATR extension, and no recent reversal. Arming still does not alert. FIRE still requires a later controlled retest, a closed reclaim candle, strong one-minute taker flow, acceptable OI, spread and depth, net R:R, BTC alignment and account risk approval.

## Manipulation handling

Live spread, bid depth, crash, OI divergence, sell-delta and composite risk remain fail-closed. Repeated historical pump/retrace episodes are retained as a caution but no longer prove the current setup is manipulated. Rejected fake-pump/rug candidates remain silent and are stored for diagnostics.

## Exit monitoring

- Futures: deterministic closed-bar momentum-fade exit added.
- Alpha: every sent IGNITION now has a Supabase trade row and is checked against stop, TP1, an 8% liquidity drain, momentum fade and six-hour timeout.
- Both ledgers retry an outcome message if Telegram fails after the database close.
- `/audit` reports only tracked, bot-issued outcomes. Earlier Alpha alerts did not include a durable entry ledger, so their exact outcomes cannot be recreated from the old event rows.
