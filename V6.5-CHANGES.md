# NEXIO v6.5 changes

## Restored live market-event information

- Finnhub US high-impact Economic Calendar restored.
- Morning Dubai summary plus 4-hour, 60, 45, 30, 15-minute and release-time warnings.
- `/events` and `/calendar` show the next 14 days and any API-access error.
- Reminder keys are stored in `nexio_events`, preventing repeated messages across Railway restarts.
- A failed Telegram reminder releases its event reservation so the next cycle can retry.

## Strict separation from trading

The calendar has its own loop and cache. It never changes BTC regime, candidate state, setup score, risk score, Futures entry, Alpha qualification, or position exits. A slow or failed Finnhub request therefore cannot delay the trading loop. Calendar messages never predict pump or dump.

## Pause correction

When `/pause` is active, Futures new entries remain paused and Alpha now runs in monitor-only mode. Existing Alpha entries continue receiving stop, TP, liquidity, fade and timeout monitoring, but no new Alpha IGNITION can be created while paused.

## Database and Railway

No new Supabase migration is required when upgrading from v6.4. The existing `nexio_events` table stores calendar reminder deduplication. Keep `FINNHUB_KEY` in Railway. `ENABLE_ECONOMIC_CALENDAR` defaults to `true`.
