# 6.9.31: Public calendar source diagnostic

When the read-only AWS fade diagnostic finds a closed calendar gate because
feeds or coverage are unavailable, it checks the BLS and BEA public schedules
individually. It reports HTTP status or fetch failure and, if parsing fails,
prints at most two BLS summary/date fields to identify an incompatible format.
It prints no API credentials and places no orders. Worker trading and the
calendar entry guard are unchanged. The BTC gate remains independent.

On AWS, pull main and run:

    sudo git -C /opt/nexio pull --ff-only origin main
    cd /opt/nexio
    sudo /usr/bin/node --env-file=/etc/nexio-fade.env scripts/fade-diagnostics.js

No service restart is needed to run this diagnostic. Use its BLS/BEA source
lines to determine why AWS cannot verify the calendar before changing live
execution behavior.
